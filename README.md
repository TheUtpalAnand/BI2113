## BI2113: Ecology and Evolution (3rd Semester)

**This repository stores Python code for assignments related to population dynamics in the BI2113: Ecology and Evolution course.**
**For solving the population dynamics problems, you can use a fantastic application 'POPULUS'. How to download POPULUS?**
1.Go to [![Download Java](https://img.shields.io/badge/Download-Java-red?style=for-the-badge)](https://www.java.com/en/download/manual.jsp)
2.Then [![Download Populus](https://img.shields.io/badge/Download-Populus-blue?style=for-the-badge)](https://github.com/cbs-rlt/populus/releases/download/6.0.0/PopulusAll_Jan_2018.jar)
and run
**Structure:**

* `assignments`: Contains code for course assignments.
* `data`: Stores datasets used in the analyses.

**How to Use:**

1. Clone the repository.
2. Explore the code in the `assignments` folder.
3. Run the code using Python.
4. Feel free to modify and experiment with the code.
